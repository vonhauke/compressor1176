# fet-comp

Plugin compressor (VST3 + Standalone, Windows) que modela o circuito de um
compressor FET clássico de 1967, revisão "painel preto" LN Rev E.

Estado atual: **etapa 0 — pesquisa e plano, aguardando aprovação.** Ainda não
há código.

- [`docs/pesquisa.md`](docs/pesquisa.md) — fontes, fatos documentados e
  suposições.
- [`docs/plano.md`](docs/plano.md) — decisões de DSP, opções de método,
  simplificações e etapas.
- [`scripts/verificar-ambiente.ps1`](scripts/verificar-ambiente.ps1) —
  verifica as ferramentas instaladas no Windows (não instala nada).

Nome definitivo do plugin: a decidir (decisão D6 do plano).
